# blade-rebirth

Reimagining of [BLADE_Alpha](https://github.com/dad2lna-coder/BLADE_Alpha).

Offline-first airport staffing (TSO / LTSO / STSO): DFO, lines, coverage, demand, shifts, function coverage, setup, and reports. No CDN or server dependency. Local assets only.

Sibling runtime: [BLADE-Runtime](https://github.com/dad2lna-coder/BLADE-Runtime).

This repo is a clean start. BLADE_Alpha stays the reference implementation; do not port it wholesale.
